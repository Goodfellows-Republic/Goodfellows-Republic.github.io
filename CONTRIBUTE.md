# Contributing to Goodfellows Republic

Thank you for your interest in contributing to Goodfellows Republic! Here's how you can help:

## How to Contribute

1. **Report Issues**:
   Found a bug? Have a feature request? [Open an issue](https://github.com/Goodfellows-Republic/Goodfellows-Republic.github.io/issues) and let us know!

2. **Submit Pull Requests**:
   - Fork the repository.
   - Create a branch for your changes (`git checkout -b feature/your-feature`).
   - Commit your work with a clear and concise message (`git commit -m "Add your message here"`).
   - Push to your branch and open a pull request.

3. **Improve Documentation**:
   Help us improve by updating and expanding documentation.

## Guidelines

- Follow the [Code of Conduct](https://github.com/Goodfellows-Republic/Goodfellows-Republic.github.io/blob/main/COC.md).
- Write clean, readable code.
- Ensure your changes are tested and documented.

## Development Workflow

1. Clone the repository:
   ```bash
   git clone https://github.com/Goodfellows-Republic/Goodfellows-Republic.github.io.git
	```
2. Install Server and API Dependencies;
3. Make Changes and Run Test;
